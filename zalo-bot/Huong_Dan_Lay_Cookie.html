🔑 Hướng Dẫn Cấu Hình Đăng Nhập Zalo Bot (Chỉ 1 Phút)

Để Bot Zalo có thể hoạt động ổn định và tự động trả lời tin nhắn, bạn chỉ cần lấy Cookie đăng nhập một lần duy nhất từ tài khoản Zalo Web theo 3 bước sau:

👉 Bước 1: Mở Zalo Web trên trình duyệt
Mở trình duyệt (Chrome, Cốc Cốc, hoặc Edge) và đăng nhập vào: https://chat.zalo.me
👉 Bước 2: Bấm F12 để mở Console
Tại trang Zalo Web, bấm phím F12 (hoặc nhấp chuột phải bất kỳ đâu → chọn Kiểm tra / Inspect). Sau đó bấm vào tab Console.
👉 Bước 3: Dán mã lấy Cookie tự động
Bấm nút sao chép bên dưới, sau đó dán vào tab Console của Zalo Web và bấm Enter:
copy(JSON.stringify({ cookie: document.cookie, imei: localStorage.getItem('z_uuid') || localStorage.getItem('imei') || 'bot-zalo', userAgent: navigator.userAgent }, null, 2)); console.log('%cĐÃ COPY XONG! Hãy dán vào file credentials.json', 'color: lightgreen; font-size: 16px; font-weight: bold;');
Đã sao chép!
👉 Bước 4: Dán vào file credentials.json
Mở file credentials.json trong thư mục zalo-bot, dán toàn bộ nội dung vừa copy (phím Ctrl + V) và bấm Lưu lại (Ctrl + S).
👉 Bước 5: Bật Bot
Chạy lại file Chay_Bot_Zalo.bat là Bot sẽ hoạt động ngay lập tức!
💡 Lưu ý: Cookie này giúp Bot đăng nhập an toàn từ chính tài khoản Zalo của bạn. Không chia sẻ file credentials.json cho người khác.
